Employee faces for agent companies. When this folder has any images (`.jpg`, `.jpeg`, `.png`,
`.webp`, or `.svg`), the app uses them instead of the bundled illustrations in `../faces`.
Everything here is committed and ships in every build, so only add images you may share.

`headshot-01.jpg` to `headshot-20.jpg` are AI-generated with Higgsfield (Soul 2); they show no
real people.
